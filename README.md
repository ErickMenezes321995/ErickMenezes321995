**Java | Spring Boot | MongoDB | Spring Security | JWT**

Backend de uma aplicação voltada ao gerenciamento de professores, alunos e treinos.

**Funcionalidades desenvolvidas:**
- Cadastro e autenticação de usuários
- Autorização por perfis
- Gerenciamento de professores e alunos
- Organização de treinos e agendas
- Integração com MongoDB
- API REST com organização em camadas

### ⚽ Backend Avaí — Gestão de Campeonatos

**Java | Spring Boot | PostgreSQL | Arquitetura Hexagonal**

Sistema backend para gerenciamento de competições de futebol virtual.

**Funcionalidades desenvolvidas:**
- Cadastro de usuários e jogadores
- Gerenciamento de times
- Organização de campeonatos
- Gerenciamento de rodadas e partidas
- Persistência de dados com PostgreSQL
- Separação de responsabilidades com arquitetura hexagonal
