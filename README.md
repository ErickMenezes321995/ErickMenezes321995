### 👨‍💻 Sobre mim

Tenho experiência prática no desenvolvimento de aplicações web utilizando React,
TypeScript e Node.js. Atualmente, meu foco está no desenvolvimento backend com
Java e Spring Boot, trabalhando com APIs REST, Spring Security, JWT e bancos
de dados relacionais e NoSQL.

e construir soluções que sejam fáceis de manter e evoluir.
